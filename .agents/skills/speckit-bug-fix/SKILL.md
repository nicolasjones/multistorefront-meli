# Corregir bug

Lee y sigue íntegramente `.specify/extensions/bug/commands/speckit.bug.fix.md`. Parte de `.specify/bugs/<slug>/assessment.md`, conserva el alcance de la corrección y registra evidencia sin alterar artefactos ajenos.
