# Data Model: Plantilla genérica de producto de automatización

No aplica — esta feature no crea, modifica ni elimina ninguna entidad de
datos. Es un rename de identificadores de proyecto/infraestructura y una
reescritura de texto de gobierno (constitución, `CLAUDE.md`, `AGENTS.md`).

Las entidades de negocio (`organizaciones`, `usuarios_organizacion`, etc.)
quedan explícitamente fuera de alcance de esta spec — son la spec futura
"Fundación multi-tenant" (ver Assumptions en `spec.md`).
